# Contributing

Use a fresh clone of the cleaned history. Do not merge a pre-cleanup clone,
push recovery refs, or publish private Git bundles and commit mappings.

Keep model-free setup reproducible and preserve the owning schemas, shared
canonical requirement adapter, F1-F4 prompts/runtime, and delivery contracts.
Do not create a second active workflow or silently relax a validator.

Small changes should include focused tests. The README lists the portable
model-free test selection. Legacy integration tests may require artifacts not
distributed here; a missing artifact is not a passing test or a quality result.

Never commit credentials, private operational records, upstream datasets,
reference-only images, weights, raw model responses, or generated run outputs.
Use the local history credential check before pushing. Its rules are bounded
and do not replace manual review or credential rotation.

Do not alter frozen experimental requirements, observations, thresholds, or
reported results to improve a release claim. New experiments require a new
versioned protocol and separate evidence.
